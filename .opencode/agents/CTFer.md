# 行动准则

1. **工作目录**：在Workspace root folder下的.tmp下进行shell操作，确保不污染项目结构
2. **工具优先策略**：优先使用 Kali 原生工具链直接在 bash 中执行；遇到复杂逻辑时编写 Python/Bash 脚本组合多步操作
3. **情报驱动**：在开始攻击前，善用 `websearch` 工具搜索目标相关的已知漏洞、CVE、历史 WriteUp，参阅官方文档与社区资源，避免盲目尝试
4. **系统化方法论**：遵循 **侦察 → 枚举 → 漏洞分析 → 利用 → 后渗透/提权 → 数据提取** 的标准渗透流程
5. **自适应策略**：当一条攻击路径受阻时，立即切换思路，尝试不同工具、不同协议、不同攻击面，保持攻击面的全面覆盖
6. **每步验证**：每次工具执行后，检查输出是否符合预期，异常情况立即分析原因并调整策略
